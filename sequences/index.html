Motifs séquentiels — Recherche de motifs fréquents

Identifier les sous-séquences fréquentes dans une base d’historiques en tenant compte de l’ordre des événements.

1. Principe

Un itemset indique quels items sont présents ensemble : {A, C} est identique à {C, A}. Une séquence indique au contraire l'ordre des événements : ⟨A → C⟩ est différente de ⟨C → A⟩.

Motif séquentiel

Une suite ordonnée, par exemple ⟨A → C⟩. Des événements intermédiaires sont autorisés : ⟨A, B, C⟩ contient ⟨A → C⟩.

Support séquentiel

Proportion d'historiques contenant le motif dans le bon ordre. Chaque historique compte au plus une fois.

Chaque historique contient une succession d’événements A, B, C ou D. L’ordre est pris en compte, mais pas la durée entre les événements.

2. Algorithme général — GSP

La recherche suit le principe de GSP : générer des séquences candidates, compter combien d'historiques les contiennent, puis conserver uniquement celles dont le support atteint le seuil fixé.

Ck — candidats

Séquences de longueur k susceptibles d'être fréquentes.

Lk — motifs fréquents

Candidats de longueur k respectant le support minimal.

  1. Comptez les événements individuels et obtenez L1.
  2. À partir de Lk−1, générez les candidats Ck en respectant l'ordre.
  3. Éliminez les candidats contenant une sous-séquence de longueur k−1 non fréquente.
  4. Comptez les historiques contenant chaque candidat et conservez Lk.
  5. Recommencez tant que des candidats peuvent être générés.
L1 = événements fréquents
Pour k = 2, 3, ... :
    Ck = prolonger les motifs de L(k-1)
    retirer les candidats avec une sous-séquence non fréquente
    compter le nombre d'historiques contenant chaque candidat
    Lk = {p dans Ck : support(p) ≥ minsup}
Retourner tous les motifs fréquents

Pourquoi élaguer ? Si ⟨A → C⟩ n'est pas fréquent, aucune séquence plus longue contenant ⟨A → C⟩ ne peut être fréquente. Cette propriété est appelée antimonotonie du support.

    5. Avantages et limites

    Avantages

    • Recherche les régularités tenant compte de l'ordre.
    • Résultats interprétables à partir des historiques.
    • Élagage justifié par l'antimonotonie du support.

    Limites

    • Nombre de candidats rapidement important.
    • Choix du support minimal parfois délicat.
    • Les durées et les événements simultanés exigent un modèle plus général.

    6. Questions pour réfléchir

    1. Inversez deux événements dans un historique. Le support de ⟨A → C⟩ change-t-il ?

    Éléments de réponse

    Cela dépend des autres occurrences du motif dans cet historique. Le support de ⟨A → C⟩ compte les historiques où un A précède un C ; inverser ces événements peut supprimer ou créer cette relation, et donc changer le support d'une unité.

    2. Augmentez le support minimal. Qu'observez-vous sur le nombre de motifs fréquents ?

    Voir la réponse

    Le nombre de motifs fréquents ne peut pas augmenter lorsque le seuil minimal augmente. Certains motifs n'atteignent plus le seuil et tous leurs prolongements peuvent être élagués par la propriété d'antimonotonie.

    3. Pourquoi ⟨A → B⟩ et ⟨B → A⟩ peuvent-ils avoir des supports différents ?

    Voir la réponse

    L'ordre fait partie de la définition d'un motif séquentiel. Un historique contenant A puis B n'implique pas qu'il contienne aussi B puis A ; le nombre d'historiques qui vérifient chaque ordre peut donc différer.

    4. Un motif fréquent signifie-t-il qu'il existe un lien causal entre les événements ?

    Voir la réponse

    Non. Un motif fréquent indique seulement une succession souvent observée. Il ne démontre pas que le premier événement provoque le second ; des facteurs communs ou le contexte peuvent expliquer cette succession.

    Pour aller plus loin — formalisation mathématique

    Considérons les 8 historiques initiaux du tableau pour effectuer les calculs de support.

    1. Représenter une base de séquences

    Soit E = {A, B, C, D} l'ensemble des événements possibles. Une séquence est une liste ordonnée d'événements. On note D = (s1, …, sN) une base contenant N séquences.

    s1 = ⟨A → B → C → D⟩   ;   s2 = ⟨A → C → B → D⟩   ;   N = 8

    Voici les huit historiques utilisés dans notre exemple :

    HistoriqueSéquenceContient ⟨A → C⟩ ?
    s1⟨A → B → C → D⟩Oui
    s2⟨A → C → B → D⟩Oui
    s3⟨B → A → C → D⟩Oui
    s4⟨A → B → D⟩Non
    s5⟨A → C → D⟩Oui
    s6⟨B → C → A → D⟩Non
    s7⟨A → B → C⟩Oui
    s8⟨C → A → B → D⟩Non

    2. Définir une sous-séquence

    Soit un motif p = ⟨p1, …, pk⟩ et un historique s = ⟨e1, …, em⟩. On dit que p est une sous-séquence de s, notée p ⊑ s, s'il existe des positions i1 < … < ik telles que pj = eij pour chaque j.

    ⟨A → C⟩ ⊑ ⟨A → B → C → D⟩,   car A est en position 1 et C en position 3.

    Les événements doivent respecter l'ordre, mais ils ne sont pas nécessairement consécutifs. En revanche, ⟨C → A⟩ n'est pas une sous-séquence de ⟨A → B → C → D⟩ : C apparaît après A.

    3. Calculer le support d'un motif

    Le support absolu compte le nombre d'historiques qui contiennent le motif. Chaque historique est compté une seule fois, même si le motif y apparaît plusieurs fois :

    N(p) = |{i ∈ {1, …, N} : p ⊑ si}|

    Le support relatif est la proportion d'historiques concernés :

    supp(p) = N(p) / N

    Dans la base de huit historiques :

    MotifHistoriques concernésSupport absoluSupport relatif
    ⟨A → C⟩1, 2, 3, 5, 755 / 8 = 62,5 %
    ⟨C → A⟩6, 822 / 8 = 25 %
    ⟨A → B → D⟩1, 2, 4, 844 / 8 = 50 %

    Le support dépend donc de l'ordre des événements : ⟨A → C⟩ apparaît dans cinq historiques, contre seulement deux pour ⟨C → A⟩.

    4. Comprendre l'élagage utilisé par GSP

    Si un motif p est une sous-séquence d'un motif plus long q, tout historique contenant q contient aussi p. Ainsi :

    p ⊑ q   ⇒   N(q) ≤ N(p)   (donc supp(q) ≤ supp(p))

    Par exemple, le motif ⟨B → A⟩ est présent dans 2 historiques (s3 et s6), tandis que ⟨B → A → C⟩ n'apparaît que dans 1 historique (s3) :

    N(⟨B → A → C⟩) = 1 ≤ 2 = N(⟨B → A⟩)

    Avec un support minimal de 3 historiques sur 8, ⟨B → A⟩ n'est pas fréquent. Par conséquent, aucun motif plus long qui contient ⟨B → A⟩ ne peut être fréquent. GSP peut éliminer ces candidats sans compter leur support : c'est la propriété d'antimonotonie.

    5. Rechercher les motifs fréquents par niveaux

    On note Ck l'ensemble des motifs candidats de longueur k et Lk ceux dont le support absolu atteint le seuil minsup :

    Lk = {p ∈ Ck : N(p) ≥ minsup}

    Dans notre exemple, avec minsup = 3 :

    NiveauMotifs fréquents obtenus
    L1⟨A⟩ (8), ⟨B⟩ (7), ⟨C⟩ (7), ⟨D⟩ (7)
    L2⟨A → D⟩ (7), ⟨B → D⟩ (6), ⟨C → D⟩ (6), ⟨A → B⟩ (5), ⟨A → C⟩ (5), ⟨B → C⟩ (4)
    L3⟨A → B → D⟩ (4), ⟨A → C → D⟩ (4), ⟨B → C → D⟩ (3)

    Les nombres entre parenthèses indiquent le support absolu. À chaque niveau, GSP génère des candidats à partir des motifs fréquents précédents, élimine ceux qui ne peuvent pas être fréquents, puis compte les historiques correspondants.

    Les motifs étudiés comportent au plus trois événements. Dans d’autres applications, une position peut contenir plusieurs items et des contraintes temporelles peuvent être imposées. Un motif fréquent révèle une régularité, mais n’établit pas de relation de causalité.
