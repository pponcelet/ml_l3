Apprentissage supervisé

Apprendre à prédire une sortie à partir d’exemples dont la réponse est connue.

1. Principe

En apprentissage supervisé, chaque observation d’entraînement possède une cible (étiquette ou valeur). L’objectif est d’apprendre une règle qui généralise à de nouvelles observations.

2. Démarche générale

  1. Définissez la cible et réunissez les exemples.
  2. Séparez les données pour l’apprentissage et pour l’évaluation.
  3. Entraînez un modèle sur les exemples d’apprentissage.
  4. Évaluez-le sur des données non utilisées pour l’ajustement.
  5. Interprétez les erreurs, la généralisation et les limites du modèle.

3. Méthodes de classification

Plusieurs approches permettent de construire une prédiction : Naive Bayes combine les probabilités conditionnelles des variables, la régression logistique estime une probabilité à partir d'un score linéaire, les k plus proches voisins utilisent les distances, les arbres de décision apprennent des règles de séparation et les SVM recherchent une frontière à grande marge.

Vous pouvez également comparer Naive Bayes, KNN, l'arbre de décision et le SVM sur les mêmes observations.

Les notions de validation et d’évaluation sont communes à toutes ces méthodes.

4. Points de vigilance

  • Le jeu de test doit rester indépendant de l’apprentissage et du choix des hyperparamètres.
  • Les données peuvent être déséquilibrées : la métrique d’évaluation doit correspondre au problème.
  • Des données d’entraînement peu représentatives peuvent limiter la généralisation du modèle.

5. Questions pour réfléchir

1. Qu'appelle-t-on une variable cible en apprentissage supervisé ?

Voir la réponse

C'est la valeur ou l'étiquette que l'on souhaite prédire à partir des variables explicatives. Elle est connue pour les observations d'entraînement, mais inconnue pour une nouvelle observation à classifier ou à estimer.

2. Pourquoi faut-il distinguer validation et test ?

Voir la réponse

La validation sert à choisir un modèle ou ses hyperparamètres. Le test doit rester indépendant de ces choix afin de fournir une estimation finale moins biaisée des performances sur des données non vues.

3. Tous les algorithmes supervisés demandent-ils la même préparation des données ?

Éléments de réponse

Non. KNN et SVM sont souvent sensibles à l'échelle des variables ; les arbres de décision le sont généralement moins pour des variables numériques. Les variables catégorielles et manquantes doivent aussi être traitées selon le modèle.

Pour aller plus loin — formalisation mathématique

Ensemble d'apprentissage et prédiction

Un jeu d'entraînement contient n couples (xi, yi). Le modèle f apprend à associer une prédiction à chaque observation : ŷi = f(xi).

Erreur empirique

Une fonction de perte ℓ mesure l'écart entre prédiction et cible. L'erreur moyenne sur l'entraînement s'écrit :

Rn(f) = (1/n) × Σi=1…n ℓ(f(xi), yi)

En classification, si la perte vaut 1 pour une erreur et 0 sinon, un modèle commettant une erreur sur cinq exemples a une erreur empirique de :

R5(f) = (0 + 0 + 1 + 0 + 0) / 5 = 0,20

Généralisation

Une faible erreur sur l'entraînement ne garantit pas de bonnes prédictions sur de nouvelles observations. Les hyperparamètres se choisissent sur un ensemble de validation (ou par validation croisée) ; le jeu de test est réservé à l'évaluation finale.
