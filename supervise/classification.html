APPRENTISSAGE SUPERVISÉ · CLASSIFICATION

Classification

Prédire une catégorie pour une observation à partir d’exemples étiquetés.

1. Principe

À partir d’un ensemble d’entraînement de couples (xᵢ, yᵢ), où yᵢ désigne une classe, l’algorithme apprend une fonction qui prédit la classe d’une nouvelle observation.

2. Méthodes courantes

Naive Bayes

Combine des probabilités conditionnelles sous une hypothèse d’indépendance des variables sachant la classe.

Expérimenter avec Naive Bayes

Régression logistique

Estime une probabilité de classe à partir d’un score linéaire, puis applique une règle de décision.

Expérimenter avec la régression logistique

KNN

Attribue la classe majoritaire parmi les k observations les plus proches. Le choix de la distance est essentiel.

Expérimenter avec KNN

Arbre de décision

Construit des décisions successives à partir des variables, sous forme de règles explicites.

Expérimenter avec un arbre

SVM

Recherche une frontière de décision en maximisant la marge, avec des noyaux adaptés aux données non linéaires.

Expérimenter avec un SVM

3. Évaluation

La matrice de confusion décrit les prédictions correctes et les erreurs par classe. L’exactitude peut être trompeuse lorsque les classes sont déséquilibrées. On utilise alors également la précision, le rappel ou le score F1 selon le problème. Retrouvez la matrice de confusion et les métriques en expérimentation.

4. Avantages et limites

Avantages

  • Un objectif prédictif clairement défini.
  • Évaluation possible sur des exemples étiquetés.

Limites

  • Nécessite des étiquettes d’apprentissage.
  • Sensible aux biais, aux déséquilibres et au décalage des données.

5. Questions pour réfléchir

1. Pourquoi une exactitude de 95 % peut-elle être trompeuse ?

Voir la réponse

Si 95 % des observations sont négatives, un modèle qui prédit toujours « négatif » obtient 95 % d'exactitude sans détecter aucun positif. La matrice de confusion, la précision et le rappel sont indispensables pour interpréter ce score.

2. Comment choisir entre Naive Bayes, régression logistique, KNN, arbre de décision et SVM ?

Éléments de réponse

Le choix dépend des données et du besoin : interprétabilité des règles, type de variables, taille du jeu, dimension, forme des frontières et coût des prédictions. Une validation sur les mêmes partitions et métriques permet de comparer les modèles.

3. Pourquoi ne peut-on pas juger un classifieur sur ses seuls résultats d'entraînement ?

Voir la réponse

Un modèle très flexible peut mémoriser les exemples et néanmoins se tromper sur de nouvelles observations. Une évaluation indépendante mesure mieux la généralisation et révèle le risque de surapprentissage.

Pour aller plus loin — formalisation mathématique

Fonction de classification

Pour C classes possibles, le classifieur est une fonction f : ℝp → {1, …, C} : à partir des p variables d'une observation, il prédit une classe.

Matrice de confusion : exemple

Considérons dix courriels, dont six sont réellement indésirables. Les prédictions obtenues sont :

Classe réellePrédit indésirablePrédit normal
Indésirable4 (VP)2 (FN)
Normal1 (FP)3 (VN)

VP désigne les vrais positifs, FP les faux positifs, FN les faux négatifs et VN les vrais négatifs.

Calculer les métriques

Exactitude = (VP + VN) / N = (4 + 3) / 10 = 70 %
Précision = VP / (VP + FP) = 4 / (4 + 1) = 80 %
Rappel = VP / (VP + FN) = 4 / (4 + 2) ≈ 66,7 %
F1 = 2 × (précision × rappel) / (précision + rappel) = 8 / 11 ≈ 72,7 %

La précision répond à la question « parmi les courriels signalés, combien sont réellement indésirables ? » ; le rappel mesure la proportion de courriels indésirables détectés. L'exactitude seule peut masquer de mauvaises performances sur une classe rare.
